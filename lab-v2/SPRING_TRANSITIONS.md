# 胶囊展开与收起：弹簧过渡

2026-09-22，基于 `29deed2d629c64b390d23dedb773a73755287916` 的后续修改。

## 体验

- PULSE 的「02 / 让灵感，慢慢展开」和 Liquid / 02 首页的「呼吸胶囊」共用同一个展开控制器。
- 宽度和高度连续变化，轻微越过目标尺寸后逐渐回稳；展开与收起采用对称的弹簧模型。
- 中途再次点击保持当时的位置与速度，顺滑转向最新状态。
- 文字保持原字号，不随容器一起拉伸；内容随可用空间逐渐显现，图标旋转与展开进度同步。
- 手机宽度和内容高度重新测量后平滑衔接；收起内容立即 inert，避免隐藏按钮获得焦点。
- 手动暂停、系统减少动态效果或页面隐藏时直接落到目标状态，避免后台动画持续运行。

## 原因与实现

原先只对 `width` 和内容网格设置过渡，展开时 `max-width` 会立即切换，可能让宽度提前跳到新上限。现在同步读取响应式 CSS 的两个尺寸端点，再用 `spring-disclosure.js` 控制实际像素宽高，CSS 最大宽度不再截断运动。

模型使用解析欠阻尼弹簧，固有角频率 8 rad/s、阻尼比 0.64。主要展开过程约半秒，随后逐渐收敛；静止起步的最大越界约为本次尺寸变化量的 7.3%，不是整个窗口尺寸的 7.3%。实际停止时间由距离和速度共同决定，通常约 1.5 秒完成尾部回稳。快速反向点击会保留速度，因此运动时间不固定。

参考 Apple 的 [Animate with springs](https://developer.apple.com/videos/play/wwdc2023/10158/) 和 [Designing Fluid Interfaces](https://developer.apple.com/videos/play/wwdc2018/803/)，采用连续位置、连续速度与可中断的交互原则。参数为本项目自行调整，并不声称复刻某一款 Apple 产品的具体动画。

`spring-disclosure.css` 仅控制容器尺寸和内容显现。原始光学引擎与材质文件保持不变，PULSE 的八个玻璃表面仍为 strength 50 / displacement scale 100。

## 验证

- 十四项测试通过。新增覆盖 30/60/120Hz 一致性、缓慢起步、有限超调、展开/收起对称性、快速反向、停顿后时间步长上限。
- 浏览器实测展开中间尺寸：340×88 起步后，依次经过约 348×100、355×111、364×124、368×131；没有一步跳到 440px 宽。
- 中途反向后观测到 `closing`，保持中间尺寸约 388×160，最终回到 340×88。收起时内容 inert。
- 桌面展开最终约 440×238.40。320px 视口下最终约 244.67×272.79，内容底部位于容器内，无页面水平溢出；胶囊入口仍可进入投票。
- 390px 视口下收起动画正常，减少动态效果模式下即时切换到 88px 高的收起状态。
- 原实验室呼吸胶囊也观测到 `opening` 的中间尺寸，使用相同控制器。
- 不把响应式模拟等同于真实触屏设备验收；本轮没有新增外部动画库。
