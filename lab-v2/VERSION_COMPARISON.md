# 版本对照与选择

比较日期：2026-09-22。GitHub 原版基准是 `GGX355/liquid-glass-template` 的 `7473866`；第二版材质基准是本地实验室的 `aa4c440`。已核对远端源码、GitHub Pages 原版页面，以及本地第二版和 PULSE 预览的实际渲染。

**针对“通透折射 + 三套场景 + 可拖动形变 + 丰富交互”的目标，推荐 Liquid / 02 作为视觉与材质基准。** GitHub 原版的流程示例和控件规范仍有价值，因此保留两个版本，不覆盖原版文件。

| 维度 | GitHub 原版 | Liquid / 02 与新版 PULSE 预览 |
| --- | --- | --- |
| 材质 | 主体是 `blur(10px)` 与渐变薄膜；边缘另加噪声位移环 | 按圆角曲面生成位移贴图，中心清晰，边缘折射；PULSE 固定强度 50 |
| 动态背景 | 五个模糊色块组成 Aurora | 极光、沙丘、蓝图；PULSE 蓝图有可见网格移动与轨道动画 |
| 惯性与形态 | 多档弹簧/果冻/面板动画 | 可拖动透镜，释放惯性与边界回弹，圆角/圆形/胶囊切换 |
| 交互样例 | 导航药丸、投票选项反馈、翻牌/刮奖/九宫格示例 | 玻璃弹性导航、倾斜卡片、展开胶囊、投票确认和灵感抽签 |
| 主题与规范 | 三态主题、字阶、间距和触控尺寸规范较完整 | 实验室有明暗模式；新版 PULSE 补齐三态主题及窄屏布局 |
| 适合用途 | 借鉴业务界面组织与设计令牌 | 作为这次要求的玻璃材质与动效展示基准 |

这不是对任一版本“完整物理光学”的认证：两个版本都属于浏览器近似效果。第二版没有实现完整光线追踪或真实色散；浏览器支持和设备表现仍需分别验证。

## 仓库组织

- GitHub 根目录保留原版，原有 `index.html`、`vote.html`、`basic.html` 和材质文件不被替换。
- `lab-v2/` 保存第二版实验室、PULSE 预览、原生 JS 模块、测试和使用说明。
- `lab-v2/SOURCE.json` 记录同步所用本地提交及文件 SHA-256，便于确认是同一套源码。
- Sites 发布目录仍使用静态资源白名单；GitHub 同步排除 `.openai`、本地证据、构建产物、依赖目录和第一版历史文件。

推荐后续从 `lab-v2/` 提取材质和交互；接入真实 PULSE 功能时，参考根目录原版的页面结构，但不要用其 blur 主材质替换第二版光学层。
