# PULSE 稳定布局与切换过渡

## 2026-10-02 原版流动导航校准

上一轮导航虽然有弹簧运动，但折射在固定轨道上，滑块仅是透明覆盖层。现恢复原版移动透镜：普通透明轨道、54px 高滑块、30px 圆角、22 强度，使用原版 520ms `left` 过渡和 520ms 挤压回弹。实际浏览器读取的两条动画与原版完全一致：移动 `cubic-bezier(.22,1,.36,1)`；形变 `cubic-bezier(.2,.75,.3,1)`，缩放依次 `1.13 .87`、`.948 1.052`、`1 1`，中间节点 .6。

交互区恢复原版文字与圆环背景的流动导航场景，与顶部活动导航双向同步，不触发滚动。连续切换、重复选择、方向键、390/320px 布局、系统减少动效已检查；减少动效时动画数量 0、过渡时长 0，无页面 warning/error。21 项现有测试通过。原版实验室源码、核心光学与其他动效保持不变。下方上一轮导航速度积分的描述已由本节取代。

## 2026-10-02 动效校正

针对后版缺少原版实验室弹性的问题，新增 `pulse-motion.js`：导航位移与速度连续积分，切换方向不重置位置；滑块随速度拉伸，停下时恢复。卡片点击恢复原地揭晓、旋转与挤压回弹，完整抽签仍通过活动区按钮进入。倾斜卡片采用有限回弹。

活动卡片在稳定网格内轻微舒展，弹窗约 1067ms 舒展并回弹、240ms 收起。中途退出从当前可见形态开始。底层活动内容用 300ms 渐隐代替突然消失；文字随玻璃短暂缩放，停止后恢复原生尺寸。

21 项测试通过，构建包含 20 个公开资源。本地 Chromium 逐帧观察导航切换 224 帧，活动区高度差为 0；滑块从 100% 移至 200%，峰值约 208.35%，拉伸峰值 1.18。弹窗实测经过约 0.87×0.78、0.99×0.98、1.02×1.03，再恢复 1×1。已检查 390/320px 布局、快速切换、拖动、卡片揭晓、胶囊、投票确认与重置、Escape、系统减少动态效果；无横向溢出和页面 warning/error。观察记录在忽略目录 `evidence/animation-restoration-traces.json`。

上述仅为本机 Chromium 检查，不代表真机触控或 GPU 性能认证。原版实验室、核心折射引擎和强度配置未改动。下方保留 2026-09-22 的历史记录，参数与资源数量以本节为准。

## 问题与调整

旧版直接隐藏当前面板，活动区随下一块内容重新计算高度。桌面观察到探索、投票、抽签依次为约 688、742、697px，后续页面随之移动。投票结果和重置也直接切换 display；弹窗只有图标动效，整体出现/消失突然。

`pulse-transitions.js/css` 让三套文案和活动卡片在共享网格内保留自然占位，按最大内容确定高度。投票表单与结果使用相同规则。没有给页面写死一个像素高度，窗口变化、字体和内容仍能参与布局；选项切换不再改变整页尺寸。

- 面板横向移动 18px 并淡入，主要位移约 660ms，略有回弹；文字只移动 10px，不缩放、不模糊。
- CSS 从当前呈现状态继续过渡，快速来回切换不建立动画队列。非当前面板立即 inert / aria-hidden，过渡结束后不可见。
- 弹窗整体约 520ms 进入、190ms 退出；保留原生焦点限制与 Escape。退出完成后再展示投票结果并聚焦重置按钮，重复确认不能产生重复回调。
- 取消打开弹窗时强制滚动到主活动区的行为。弹窗不完全处于活动背景范围内时增加背景遮罩，以保持正文可见；玻璃本体仍透明。弹窗打开时隐藏底层活动文案，避免两层文字重叠。
- 减少动态效果或暂停时直接到达目标状态；键盘方向键/Home/End 导航保留。加强导航焦点、选中选项和不可用按钮的状态辨识。

## 验证

- 18 项自动测试通过，其中新增 4 项检查弹窗延迟退出、重新打开中断、减少动效时结束退出以及 Escape；构建与 JS 语法检查通过，无新增依赖。
- 本地 Chromium 在桌面和 768/390/320px 宽度切换三个页签，活动区和文档高度保持一致。桌面活动区约 745px；390px 约 956px；320px 约 957px；768px 约 722px。自然尺寸随视口改变属于正常响应式布局。
- 观察到切换中间帧 opacity 为 0.863、translate 为 0.659px，确认有连续过渡；快速多次选择最终只保留最后一个可交互面板。
- 投票确认、结果、重置、抽签弹窗、Escape、键盘导航和减少动效均复核。直接页面复核流程无 warning/error 日志。探索透镜的方向键左移仍为 16px。
- 检查极光、蓝图、沙丘，以及浅/深色页面，文字保持原生尺寸；窄屏无横向溢出。
- 本地观察页 `evidence/motion-probe.html` 在每次手动切换后的 900ms 内采样 rAF 间隔与活动区高度。三次采样约 143–144 个间隔：中位数 6.2ms，P95 6.3–6.4ms，最大 12.5ms；高度变化为 0，观察窗口中长任务为 0。结果保存在忽略目录 `evidence/panel-frame-samples.json`。

上述是当前桌面浏览器的短时主线程观察，包含本地观察页的采样开销，不等同于完整 GPU 帧率、真机触控或低端设备性能认证。辅助 iframe 观察页的控制期间另记录一条 MutationObserver 参数错误，直接页面未复现；站点与观察页源码均不使用 MutationObserver，因此不把辅助页当作无错误运行的证据。Safari/Firefox 和真实触屏仍未实测。
