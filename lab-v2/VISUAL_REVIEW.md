# PULSE 视觉与交互复核

日期：2026-09-22。复核基线：`3462763109900957839ce4c00514cb8d6f93c25c`。

## 已落实的调整

| 观察到的问题 | 调整 |
| --- | --- |
| 多处说明只有 6–10px，手机阅读费力 | 主要正文/操作文字调整至 12–14px；窄屏导航最低 11px，装饰英文仍小于正文；增加行距和标题字重 |
| 极光亮区冲淡白字，背景大字穿过正文 | 在背景层安排明暗渐变，移开装饰大字；投票和弹窗状态降低大字亮度，探索模式保留明显折射纹理 |
| 深色页面的辅助文字偏弱 | 调整辅助色和标题强调色；暖色卡片使用深棕字，浅绿胶囊使用深绿字 |
| 松手速度依赖最后一次事件，偶发滑行突兀 | 改用最近 90ms 的位移估计，停留后衰减，向量速度上限 1100px/s；拖到边界后不累积无法显示的位移速度 |
| 倾斜卡片用变形后的边界算角度，可能反馈抖动 | 使用静止父容器定位；倾角限制 ±5°；以临界阻尼方式跟随和回正 |
| 鼠标事件直接反复读写高光样式 | 高光位置更新合并到每帧一次，集中读取布局后写入样式；离开、暂停和卸载时清理 |
| 调整窗口时已移动透镜突然归位 | 保留用户位置，仅在超出新边界时限制位置；“透镜归位”仍可显式恢复 |
| 文字放大后手机布局更紧 | 手机探索区域增加高度，说明与按钮分行；320px 胶囊展开按钮纵向排列；保留清晰焦点样式和减少动态效果支持 |

## 保留边界

- `liquid-glass.js`、`liquid-glass.css`、`visual.css`、`optics.js`、`motion.js` 与 Liquid / 02 参考提交 `aa4c4405a49701bff2eb8743ff812f3043e8e739` 完全相同。
- 八处玻璃仍使用 strength **50**，对应 SVG displacement scale **100**。没有弱化折射，也没有添加不透明玻璃阅读面板。
- 明暗调整位于玻璃后方的 PULSE 背景层；三个动态场景、三种透镜形态、惯性回弹、弹性导航和展开胶囊均保留。
- 原实验室首页不受 PULSE 专属样式影响。真实 PULSE 业务、账户、投票服务和数据库未接入。

## 验证证据

- 十项自动测试通过，涵盖原有光学/滑行模型，以及 30/60/120Hz 速度估计、停留/边界情况、斜向速度上限、事件抖动和倾斜阻尼稳定性。
- JavaScript 语法检查、静态构建和变更空白检查通过。发布清单包含十三个公开资源；测试、文档和本地服务不进入 Sites 资源包。
- Chromium 检查宽度 1280、768、390、320px，观测状态无页面水平溢出。320px 投票与弹窗内容可见；390px 胶囊透镜宽 280px，位于 339px 场景内。
- 桌面实际拖动：指针向左移动 153px，透镜左位置由 631 到 377，松手后继续移动且 held 状态清除。
- 卡片倾斜到约 X 3.12° / Y 4.12°，移开后恢复无 transform；场景不在视口内时下方卡片依然正常工作。
- 确认投票显示选中的目的地，重置恢复表单；随机灵感弹窗打开/关闭；胶囊中的入口可切换活动。
- 深色底色实测为 `rgb(17,27,25)`；临时主题设置已恢复为跟随系统。
- 系统减少动态效果下显示“已减少动效”，按钮禁用，背景暂停，方向键仍可移动透镜；增强对比度设置触发更深的背景明暗层。所有临时媒体/视口模拟已恢复。
- 所检查流程没有浏览器 warning/error 日志。

## 固定底色文字对比度

按照 [W3C 的相对亮度与对比度说明](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html) 计算 CSS 颜色，数值为四舍五入显示。

| 用途 | 文字 / 背景 | 比值 |
| --- | --- | --- |
| 浅色正文 | `#1b3029` / `#f7f7f2` | 13.02:1 |
| 浅色辅助文字 | `#53645b` / `#f7f7f2` | 5.85:1 |
| 浅色标题强调 | `#526e50` / `#f7f7f2` | 5.27:1 |
| 深色正文 | `#e7ede7` / `#111b19` | 14.79:1 |
| 深色辅助文字 | `#bcc9bf` / `#111b19` | 10.25:1 |
| 深色标题强调 | `#b2c9a9` / `#111b19` | 9.89:1 |
| 可用的主要按钮 | `#254239` / `#f0f6ee` | 9.97:1 |

这些数值只适用于上述固定色组合，不代表动态透明玻璃上的全部文字都达到相同比值。玻璃区域进行的是多场景视觉复核，尚未穷尽所有动画帧、拖动位置和浏览器，因此不宣称全面 WCAG 合规。减少动态效果的处理参考 [W3C 交互动效说明](https://www.w3.org/WAI/WCAG22/Understanding/animation-from-interactions.html)。
