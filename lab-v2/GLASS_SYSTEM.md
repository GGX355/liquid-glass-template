# PULSE 全局玻璃与折射设置

日期：2026-09-22。基线：`47f7a428a76a2b8834af5d920b991c45d5ad808b`。

## 官方设计依据

[Apple WWDC25 — Meet Liquid Glass](https://developer.apple.com/videos/play/wwdc2025/219/) 说明材质应随背景和组件尺寸适应，较大的表面可以有更明显的透镜效果；文字通过色调和明暗处理保持清晰。内嵌控件应使用薄的透明覆盖层，避免玻璃叠玻璃。视频还以不透明按钮为反例，建议通过透明着色融入玻璃。

该公开说明未提供通用的折射百分比。这里的 `strength` 是我们 SVG 位移实现的强度标尺，`feDisplacementMap` 的 scale 为其两倍，不是物理折射率，也不是 Apple 官方数值。原始 `liquid-glass.js`、`liquid-glass.css`、`visual.css`、`optics.js`、`motion.js` 仍与 Liquid / 02 的 `aa4c4405a49701bff2eb8743ff812f3043e8e739` 完全相同。

## 选择与实现

| 角色 | 轻柔 | 均衡（默认） | 鲜明 |
| --- | ---: | ---: | ---: |
| 主透镜 | 32 | 50 | 60 |
| 活动面板、弹窗、邀请卡、展开胶囊 | 28 | 40 | 50 |
| 导航轨道 | 22 | 30 | 40 |
| 独立小控件 | 14 | 22 | 30 |

对比三档后采用均衡：保留用户喜欢的主透镜 50；较小控件减轻边缘位移，保留可见的曲面高光。轻柔和鲜明是可随时比较的视觉选项，没有将这些值宣称为客观最优。设置以 `pulse-liquid-profile` 保存，存储受限时仍可使用。

`pulse-glass.js` 负责角色、实例和设置；`pulse-glass.css` 负责透明着色、高光、轮廓、状态和布局。导航、帮助/说明、投票选项、提交/确认/再体验一次、抽签、弹窗关闭、主题、场景/形状/光感、动效、归位、胶囊操作和页尾入口都具有玻璃外观。文字、标题与页面正文保持普通内容排版。

当前 DOM 有 25 个独立光学实例和 11 个透明内嵌覆盖层。所有 button 均自身或经父容器承载玻璃。内嵌按钮共享父级折射，`backdrop-filter:none` 防止重复扭曲；其透明着色和高光仍可透出背景。导航选中项也按此原则处理。旧版 `position:static` 的说明按钮改为 `relative`，确保光学伪元素只覆盖按钮自身。

## 验证

- 14 项现有光学、惯性、倾斜、弹簧测试通过；语法、构建和 Git 空白检查通过。无新增依赖。
- 构建白名单 17 个资源；发布包另含部署清单。历史第一版、测试、文档、本地证据不进入 Sites 包。
- Chromium 实际渲染比较轻柔/均衡/鲜明，检查极光、沙丘和蓝图；浅色、深色主题可用。
- 确认投票与“再体验一次”完成操作；按钮计算背景为 `rgba(0, 0, 0, 0)`，父级保留 SVG 折射，截图可看到穿过按钮的背景纹理。
- 1280、768、390、320px 视口无文档水平溢出，窄屏光感按钮换行正常。
- 胶囊收合/展开过程观察到连续的 `closing` / `opening` 中间高度，保留原弹簧逻辑；减少动效模拟下立即到达终态，玻璃保留。媒体和视口模拟已恢复。
- 选择均衡后刷新仍保持；所有按钮有玻璃承载，body 无错误 aria-pressed 属性；检查流程没有 warning/error 控制台日志。

边界：只更新独立 PULSE 视觉体验，不接入真实业务。实验室首页保留现有材质控制。Safari/Firefox、真机触控、低端 GPU 性能仍未实测。增加了独立控件滤镜，不能据桌面检查宣称性能无影响；动态透明背景的文字对比度没有覆盖所有帧，不宣称全面 WCAG 合规。
